# SportsLabResearch-Rugby7-Referee-Physical-Fatigue-Analyzer

Scientific software developed by SportsLabResearch for the analysis of external load, internal load and physical fatigue in Rugby Sevens referees.

## Current status

Version: v0.1.0-alpha

## Main features

- Analysis of one referee.
- Analysis of multiple referees.
- Batch processing.
- Scientific reports.
- Public anonymized dataset generation.
- Word and Excel reports.
