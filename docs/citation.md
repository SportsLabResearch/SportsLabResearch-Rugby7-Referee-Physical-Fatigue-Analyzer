# Citation

The project is prepared for archival through GitHub–Zenodo integration. The final DOI is created by Zenodo when a GitHub release is archived.

## Suggested citation

Until the first archived release receives a DOI, cite the software as:

> SportsLabResearch. (2026). *Rugby7 Referee Physical Fatigue Analyzer* (Version 0.1.0-alpha) [Computer software]. GitHub.

Repository:

```text
https://github.com/SportsLabResearch/SportsLabResearch-Rugby7-Referee-Physical-Fatigue-Analyzer
```

## Zenodo release workflow

1. Connect the GitHub repository in Zenodo.
2. Enable archiving for the repository.
3. Create a versioned GitHub release.
4. Wait for Zenodo to create the archived record.
5. Add the generated DOI badge and citation to this page and to `README.md`.

## BibTeX template

```bibtex
@software{sportslabresearch_rugby7_physical_fatigue_2026,
  author  = {{SportsLabResearch}},
  title   = {Rugby7 Referee Physical Fatigue Analyzer},
  year    = {2026},
  version = {0.1.0-alpha},
  url     = {https://github.com/SportsLabResearch/SportsLabResearch-Rugby7-Referee-Physical-Fatigue-Analyzer}

```

Replace the repository URL with the Zenodo DOI after the release has been archived.
