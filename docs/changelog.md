# Changelog

## 0.1.0-alpha

Initial alpha release with:

- interactive identified and private coded modes;
- one, multiple and batch referee selection;
- Excel and CSV loading;
- external-, internal- and mechanical-load summaries;
- trend figures and normalised heatmap;
- Excel audit output;
- practical Word reports;
- GitHub Pages documentation and Zenodo metadata.

## Planned improvements

- automated tests and fixture datasets;
- stronger separation of analysis and report generation;
- formal schema validation for vendor exports;
- configurable thresholds;
- expanded bilingual documentation;
- stable public Python API.
