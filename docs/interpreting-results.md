# Interpreting results

The analyzer describes change across the selected match sequence. Results should be interpreted as a multidimensional profile rather than as a single fatigue score.

## Practical reading order

1. Confirm that all selected matches were loaded correctly.
2. Inspect match duration and data completeness.
3. Compare absolute volume with relative intensity.
4. Review external and internal load together.
5. Check whether trends are consistent across multiple indicators.
6. Consider contextual factors such as match role, stoppages, temperature and tournament schedule.

## Direction of change

A lower value is not automatically worse or better. For example, reduced metres per minute could reflect fatigue, but it could also reflect match structure. Heart-rate responses can be influenced by heat, hydration, stress and sensor quality.

!!! note "Scientific interpretation"
    The software supports descriptive and practical analysis. Causal claims require an appropriate study design, validated thresholds and statistical modelling beyond automated report generation.
