# Privacy and anonymisation

The repository supports a privacy-oriented coded workflow, but safe research sharing still requires governance and manual review.

## Personal data that may appear

- names and folder names;
- photographs;
- profile spreadsheets;
- document metadata;
- original filenames;
- free-text fields;
- dates or event details that enable re-identification.

## Release checklist

- [ ] Run private coded mode.
- [ ] Remove photographs and real-name profile files.
- [ ] Inspect Word document properties and embedded media.
- [ ] Inspect Excel hidden sheets, comments and metadata.
- [ ] Confirm that file paths are not exposed.
- [ ] Review small-cell and linkage risks.
- [ ] Keep the identity-code key in restricted storage.
- [ ] Confirm consent, ethics and data-sharing permissions.

!!! warning
    The software cannot guarantee GDPR compliance or irreversible anonymisation. Compliance depends on the full data lifecycle, legal basis, institutional controls and disclosure risk.
