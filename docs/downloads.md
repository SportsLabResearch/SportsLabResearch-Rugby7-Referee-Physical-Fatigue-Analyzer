# Downloads

## Source code

Use GitHub releases for immutable software versions. Each release should contain the source archive automatically produced by GitHub.

## Documentation

The documentation workflow publishes the `main` branch to GitHub Pages. A local static copy can be built with:

```bash
mkdocs build --strict
```

The generated site is written to `site/`.

## Research artefacts

Use Zenodo for DOI-backed software releases and approved public datasets. Keep sensitive or identifiable source data outside public deposits.
